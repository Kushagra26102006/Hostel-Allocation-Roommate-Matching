# HostelHub Bug Fixes & Security Audit Report (`FIXES.md`)

This document summarizes all bug fixes, security hardening, and architectural improvements completed across Phases 1 through 7 in the HostelHub monorepo (`apps/web`, `apps/worker`, `packages/db`, `packages/shared`, `packages/domain`).

---

## 2. Items Not Fixed or Intentionally Omitted

1. **Prisma ORM Migration**: Not performed because Mongoose is the chosen ORM for MongoDB per ADR 0001. All repository layers and schema plugins are built natively on Mongoose 8.
2. **Signal Handlers in `packages/db`**: Kept intact as requested in ground rules since they gracefully handle database disconnects without causing process deadlocks.
